# مسار التسويق وإدارة الإعلانات

نظام متابعة المصروفات التسويقية وقياس أداء القنوات الإعلانية — واجهة عربية كاملة (RTL).

> موقع ثابت بالكامل: HTML + CSS + JavaScript، بدون أي مكتبات خارجية وبدون خطوة بناء.
> يكفي فتح `index.html` في المتصفح.

---

## المزايا

| | |
|---|---|
| **لوحة الإدارة الرئيسية** | بطاقات القنوات، مؤشرات الأداء، نسبة التسويق، ومقارنة تلقائية بالفترة السابقة المكافئة |
| **الإدخالات اليومية** | تسجيل الصرف والمبيعات يوماً بيوم لكل قناة، مع إضافة وتعديل وحذف |
| **التقرير الشهري** | ملخص شهراً بشهر + الأداء حسب المنشأة، قابل للطباعة |
| **القنوات والمنصات** | إدارة قنوات الصرف وألوانها وأيقوناتها |
| **المنشآت** | تعدد الفروع/الجهات مع تصفية كل الشاشات حسب المنشأة |
| **سجل التعديلات** | توثيق كل إضافة وتعديل وحذف (آخر 500 عملية) |
| **النسخ الاحتياطي** | تصدير/استيراد JSON، وتصدير CSV متوافق مع Excel العربي |

## المؤشرات المحسوبة

| المؤشر | المعادلة |
|---|---|
| ROAS | المبيعات ÷ الصرف التسويقي |
| متوسط تكلفة الطلب | الصرف التسويقي ÷ عدد الطلبات |
| نسبة التسويق | (الصرف التسويقي ÷ المبيعات) × 100 |
| الربح | المبيعات − الصرف التسويقي − تكلفة البضاعة |

## التشغيل

افتح `index.html` مباشرةً، أو شغّل خادماً محلياً:

```bash
python -m http.server 8777
```

ثم افتح `http://localhost:8777`.

### تجربة سريعة

من صفحة **الإعدادات ← بيانات تجريبية** يمكنك توليد بيانات وهمية لآخر 75 يوماً لاستعراض النظام.

---

## النشر على GitHub Pages

المستودع جاهز للنشر كما هو (موقع ثابت في الجذر):

1. ادفع المستودع إلى GitHub.
2. من `Settings ← Pages`، اختر **Source: Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم `Save`.
4. سيصبح الموقع متاحاً خلال دقيقة على `https://<username>.github.io/<repo>/`.

## أين تُحفظ البيانات؟

جميع البيانات تُحفظ في **`localStorage` داخل متصفحك فقط** — لا يوجد خادم ولا قاعدة بيانات ولا يغادر أي رقم جهازك.

يترتب على ذلك:

- البيانات مرتبطة بالمتصفح والجهاز؛ لا تتزامن بين الأجهزة ولا بين المستخدمين.
- مسح بيانات المتصفح يمسح بياناتك.
- **نزّل نسخة احتياطية بانتظام** من صفحة الإعدادات.
- زر «تسجيل الخروج» شكليّ فقط — لا توجد حسابات ولا صلاحيات في هذه النسخة.

للاستخدام المشترك بين عدة مستخدمين أو أجهزة، يلزم ربط النظام بخادم وقاعدة بيانات.

## بنية المشروع

```
index.html              الهيكل والواجهة
assets/css/style.css    التنسيقات (RTL، متجاوب، دعم الطباعة)
assets/js/store.js      طبقة البيانات، الحسابات، التخزين والتصدير
assets/js/charts.js     التنسيق الرقمي والرسوم البيانية (SVG خالص)
assets/js/app.js        الموجّه والشاشات والأحداث
```

## ملاحظة على الألوان

ألوان القنوات مأخوذة من لوحة ثابتة تم التحقق منها آلياً: نطاق الإضاءة، حد التشبع،
والفصل البصري بين الألوان المتجاورة لأصحاب عمى الألوان (ΔE 14.8) وللرؤية الطبيعية (ΔE 19.9).
اللون تابع للقناة ولا يتغيّر عند الفرز أو التصفية، وكل صف في الرسوم يحمل اسمه وقيمته نصّاً،
فلا يعتمد التمييز على اللون وحده.
